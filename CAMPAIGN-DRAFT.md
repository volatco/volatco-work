# Volatco Multicomputer — Campaign Foundation

## Campaign position

**Volatco Multicomputer** is a compact, massively parallel computer for builders who need local, direct control of their systems.

It brings 288 independent F18A computing nodes, arranged across two GA144 chips, to one experimental platform. Volatco is made for hands-on work in real-time control, robotics, sensing, edge systems, and parallel-computing research—without requiring a cloud runtime or a heavyweight operating system.

This campaign offers one clear, dependable baseline: the Volatco Multicomputer, based on an established hardware build and refreshed with an updated flash configuration.

## Short description

Volatco Multicomputer combines two GA144 chips into 288 independent F18A computing nodes for real-time, event-driven, Forth-native computing. It is an experimental platform for builders exploring local control, distributed coordination, and efficient parallel systems.

## The story

Modern computing is often powerful but remote from the systems it controls. Layers of software, operating systems, and cloud services can make timing and behaviour harder to see, test, and direct.

Volatco takes a different route. Its many small independent computers work locally, close to sensors, machines, and experiments. Rather than forcing every task through one large processor and a heavyweight software stack, Volatco lets builders explore a distributed, event-driven way of computing.

The result is a practical starting point for experiments where low latency, low power use, direct control, and parallel behaviour matter.

## What Volatco is for

- Real-time control and sensor coordination
- Robotics and distributed control loops
- Local edge processing without mandatory cloud round trips
- Autonomous and long-running experimental systems
- Education and exploration of Forth and parallel computing

## The Volatco Multicomputer

This campaign is deliberately focused on one well-defined product: the **Volatco Multicomputer**.

It is based on an established hardware build and includes an updated flash configuration. By concentrating on a dependable baseline, we can put the emphasis where it belongs: learning, experimentation, technical documentation, and real-world use.

### Core architecture

- Two GA144 chips
- 288 independent F18A computing nodes
- Forth-native development model
- Event-driven, massively parallel architecture
- Compact hardware for local experimentation

### Interface and setup

The Volatco Multicomputer uses an external USB–FTDI interface for host connection and setup. Before launch, the campaign must state one of the following clearly:

- the exact compatible adapter that a backer supplies;
- an adapter included in the reward; or
- an adapter offered as a separately priced campaign add-on.

Do not imply that a USB interface is integrated into the Multicomputer unless it is included in the shipped product.
